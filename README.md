修改自清华大佬翁家翌的版本. 在此特别感谢大佬(膜拜).

只是做了一点点很简单的工作, 甚至可能前人已经做过了. 但是我还是决定上传.
祝各位同学答辩顺利, 毕业快乐!

\end{block}
